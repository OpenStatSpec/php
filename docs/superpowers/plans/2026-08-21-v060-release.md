# OpenStatSpec PHP v0.6.0 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate and publish the PHP adapter v0.6.0 release from `main` at merge commit `2c3c426`.

**Architecture:** Keep the existing official transformation implementation and service-matrix workflow unchanged unless a release gate finds a concrete defect. Version the already prepared changelog, validate against an isolated exact specification v0.3.0 checkout, then publish an annotated tag and GitHub Release.

**Tech Stack:** PHP 8.4/8.5, Composer, PHPUnit 11, GitHub Actions, Packagist, OpenStatSpec specification v0.3.0.

**Spec:** `docs/release-readiness.md` and `docs/transformations.md#v060-migration`.

## Global Constraints

- Branch must be `main` at merge commit `2c3c426` before release.
- Specification must be `v0.3.0` at exact commit `cd8f198c68b849eb8ed018a894670a0904c2181d`.
- Claims are Transformation Plan 0.1/0.2, SPSS Frontend 0.2, and In-Place Transformation 0.1/0.2.
- `openstatspec-transformation-plan-v1`, SPSS `STRING`, and SPSS `DELETE VARIABLES` must remain removed.
- MySQL, MariaDB, and Dolt require pre-provisioned and catalogued targets; Dolt commits remain caller-owned.
- Do not tag or publish until every required local and CI gate is green and the PHP working tree is clean.
